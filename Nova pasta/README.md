Este projeto é um sistema simples de cadastro de medicamentos feito em Python.
O programa permite cadastrar medicamentos, listar os medicamentos cadastrados e buscar um medicamento pelo nome.
Os dados são salvos em um arquivo CSV para não serem perdidos quando o programa for fechado.

Como executar:
Ter o Python instalado no computador.
Abrir a pasta do projeto.
Executar o arquivo main.py.

No terminal, também é possível executar com:

python main.py

Funcionalidades:
Cadastrar medicamentos.
Listar medicamentos.
Buscar medicamentos pelo nome.
Salvar os dados em arquivo CSV.
